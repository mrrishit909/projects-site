# ChangeWorks — static site brief (Mode B)

Visual direction (P09-GOAL-03): a **strategy atelier**. Parchment ground `#f3ead8`, deep green `#17382b` for text and
structure, brass `#b08d57` (text on parchment `#7d6236`) for emphasis, rule `#d9ccb2`, muted `#5c5a52`, a dry red
`#9e3b2f` only for refusals and overallocation. Type: a transitional serif for display, a humanist sans for reading, a
mono for figures. Principal representations: the **roadmap** (initiatives as bars on periods with dependency arrows
and resource lanes) and the **cash-flow table** with the assumption versions that produced it beside each row. Must
not resemble the other labs.

Routes under `/projects-site/labs/changeworks/`: `/` landing; `/portfolio/` portfolio overview (entry: costs,
benefits by class, confidence labels, the double-count residual); `/baseline/` baseline evidence (volumes, effort and
errors, approved versions); `/business-case/` business case (entry: the cash-flow model, NPV, both paybacks, the
assumption versions; the golden case recomputed); `/sensitivity/` sensitivity lab (rates, adoption ramp and cost
scenarios, simulated in browser memory); `/roadmap/` (entry: dependencies, feasible starts, resource conflicts);
`/impact/` change impact (stakeholder groups and operating changes); `/readiness/` readiness review (the five
dimensions with labels, assessment not probability); `/benefits/` benefits register (owners, observations, realization
within a benefit type, the attribution caveat); `/forecast/` forecast comparison (original vs revisions vs observed);
`/evidence/`; `/case-study/` (entry: investment logic and attribution limits). Same routing, manifest, honesty, motion
and Playwright evidence rules as the other apps.
