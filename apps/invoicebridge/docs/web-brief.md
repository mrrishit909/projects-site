# InvoiceBridge — static site brief (Mode B)

Visual direction (P05-GOAL-03): a **document reconciliation desk**: warm paper `#f6f1e7`,
charcoal `#2b2b2b`, muted teal `#2f7f86` (text `#246269`), rule `#d6cfc0`, ink `#1e1e1e`.
Type: a typewriter-ish mono for document fields beside a serif for reading. Principal
representation: **evidence beside decision**: the invoice (as structured fields with source
hash and correction lineage) on the left, the match result, exceptions and approval trail on
the right. Must not resemble the other labs.

Routes under `/projects-site/labs/invoicebridge/`: `/` landing; `/intake/` (entry: import
simulation, duplicate detection shown); `/invoices/` invoice detail (entry: the golden pair);
`/matching/` matching panel (entry); `/duplicates/`; `/exceptions/` queue (entry); `/approvals/`
desk; `/vendors/`; `/exports/` export review; `/audit/` timeline; `/case-study/` (entry).
Same routing, manifest, honesty, motion and Playwright evidence rules as the other apps.
