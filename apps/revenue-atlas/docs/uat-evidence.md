## Defects and findings

* DEFECT G-01 (known): credits are windowed by the shipment's `shipped_at`, not `credit_date` (D-01). Failing assertions: `after["net_merchandise_sales"] == "225.00"` (got 135.00) in the DETECT test and `later["merchandise_credits"] == "90.00"` (got 0.00) in the RECOVER test.
* DEFECT-1: FX_RATE_MISSING quarantine is not persisted. Failing assertion: `GET /data/quarantined_records` equals `[("shipment_lines","sl-eur-1","FX_RATE_MISSING")]` (got `[]`). The metrics `meta.exclusions.quarantined` does count it, and `meta.exclusions.quarantined_records` (table count) stays 0 meanwhile.
* Finding (not a failing test): C01 is insert-only, so a wrong price cannot be corrected on an existing line id; recovery is a new order or a reseed. A batch with a child row whose parent is only in the database is rejected ORPHAN_REFERENCE.
* Finding: `contribution_margin_rate` can be below zero (-1.53 observed); D-05 says rates are in [0, 1].
