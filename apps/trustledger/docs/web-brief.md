# TrustLedger — static site brief (Mode B)

Visual direction (P07-GOAL-03): an **evidence library**. Ivory `#f4efe4` ground, forest `#1f4d3a` (text `#173c2d`),
restrained vermilion `#b8432a` for critical failures only, rule `#d8d0bf`, ink `#1c1c1a`, muted `#6b6f68`. Type: a
transitional serif for display, a humanist sans for reading, a mono for figures. Principal representations: the
**glossary** (competing definitions and their versions side by side) and the **lineage graph** (declared edges solid,
observed edges thick, inferred edges dashed and labelled, never styled as observed). Must not resemble the other labs.

Routes under `/projects-site/labs/trustledger/`: `/` landing; `/catalog/` catalog home (entry: search datasets,
fields and owners; ownership coverage); `/glossary/` (entry); `/scorecard/` quality scorecard (entry: dimensions
separate, the weighted score with its weight version, critical failures shown independently with the override);
`/rules/` rule detail (entry: eligible population, failing examples, comparable runs); `/issues/` issue workbench
(entry: ownership, aging, claimed vs resolved); `/lineage/` lineage explorer (entry); `/duplicates/` duplicate review
(side-by-side evidence, uncertainty, no automatic merge); `/merges/` merge history (reversible mappings);
`/impact/` impact preview (downstream metrics affected by a definition change); `/evidence/`; `/case-study/` (entry).
Same routing, manifest, honesty, motion and Playwright evidence rules as the other apps.
