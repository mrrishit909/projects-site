## Migration

No path changed. Old home anchors (`#projects`, `#<slug>`, `?q=`, `?kind=`) still forward to the archive from the
inline script in the home's head; `#feature-<slug>` chapters keep their ids; the previous `#check` and `#experience`
anchors are gone (the check lives inside the Florida chapter, the experience inside `#about`), and an unknown hash is
forwarded to the archive as before.

## Content schema per case page (from project.json)

Summary: Problem (first 190 characters of `problem`, plain text), Role (fixed line), Tools (`tech`), Status (derived:
frozen / demo / repository, plus the repository's last push), Evidence (demo, repository, live site). Narrative: the
five sections (problem, built, how with numbered steps and code, results, next), the cover with a caption, the facts
strip from data/github.json, the note. Neighbours: previous and next in date order. Edge cases handled by the
template: titles over 34 characters (`h1.long`), no demo, no GitHub record (no facts strip), no note, long tables and
code (scroll inside), images (bordered, zoomable), 142 demos, archived work (trading-bot).
